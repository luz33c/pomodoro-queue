01围绕方案 1 的五套白噪音方案一览

五套方案共用完全相同的方案 1 主流程与暗色模式，差别在于白噪音的能力形态与控制落点。点击任意卡片跳转到对应演示，浏览器内可直接用 Web Audio API 合成试听。

五套白噪音方案共用的底线规则（继承自方案 1）
  • 方案 1 核心体验零削弱：首页仍是倒计时 + 宠物场景 + 双入口；按任务创建仍是 2 步「圈卡丢盒 → AI 排番茄」；专注底部常驻时间线；休息全屏走去喝咖啡并亮起打卡格（番茄 / 骨头 / 小鱼）。
  • 暗色模式双层独立可控：页面/系统外观与应用内主题均支持「跟随系统 / 暖纸浅色 / 暖墨深色」，2px 卡片描边、硬偏移阴影、纸箱质感、弹窗与休息页气泡全部语义化适配，深色下无刺眼闪白。
  • 白噪音生命周期规则：默认静音、仅由用户手势解锁开启；专注中平滑淡入，暂停/终止立即淡出，休息段默认静音（可选切换「休息极轻伴奏 20%」）；待开始时开启或试听会播放 4 秒预览后进入待命。
  • 本机隔离与容错：音量与开关只保存在本机，不跨设备突然出声；音频被系统/浏览器拦截时在声控区与 Island 提示重试，番茄计时绝不中断或回滚。

05技术架构与本仓库真实改动落点

基于当前仓库代码（apps/app、apps/desktop、packages/core）梳理最小调用链路。白噪音播放器与主题偏好全部归属本机宿主层，不污染服务端队列写路径。

【状态投影与音频驱动链路】
队列快照 (packages/core 绝对时间段投影)
  ├── 阶段 ∈ {focus} && !paused && localSound.enabled
  │     └── 有效音轨 (单音 / W3 多轨 / W4 当前段绑定音色)
  │           → 宿主 AudioAdapter.play(tracks, masterVol, rampMs=140)
  ├── 阶段 ∈ {short, long}
  │     ├── breakMode === 'mute' → fadeOut(160ms) + stop
  │     └── breakMode === 'duck' → setMasterGain(masterVol * 0.2)
  └── 暂停 / 结束 / 登出 → fadeOut(120ms) + release

【主题同步链路（无闪烁 FOUC 防护）】
localStorage('pomodoq-theme') ──▶ 首帧内联脚本写 <meta name="color-scheme">
  └── CSS :root:has(meta) + light-dark() + [data-theme] 回退
        ├── 文档/桌面外壳随系统或手动覆写
        └── 主窗应用独立支持 color-scheme: only light | only dark
【宿主分层职责】
apps/app (React SPA · 认证后公共布局)
  ├── ThemeStore (Zustand · 持久化本机 theme)
  ├── AmbientAudioStore (Zustand · 本机音量/音色/混音)
  └── HostAdapter.audio
        ├── Web 实现: AudioContext + 6 路循环 Buffer
        │            + BiquadFilter + GainNode (零外链)
        └── Desktop 实现: window.tsuDesktop RPC
              └── apps/desktop 主进程 (Bun)
                    └── Swift Helper (AVAudioEngine + Island)
                          ↳ 唯一发声源，WebView 不重复播
为什么不把白噪音状态同步到服务端？ 用户常在公司电脑静音开会、回家戴耳机听雨声；将开关与音量留在各设备本地存储（仅可选同步自定义配方名），既避免另一台设备突然外放社死，也省去额外的实时写冲突与服务端带宽。
apps/app/src/lib/host/types.ts

在 HostAdapter 新增可选 audio: HostAudioController（setMix / setMasterVolume / stop / subscribeStatus）与 island 桥接契约，Web 与 Desktop 通过 #/lib/host/runtime 各自实现。

apps/app/src/app/routes/(auth)/route.tsx

在 AuthLayout 的 <AppShell> 之上挂载队列投影订阅器与本机音频调度器，保证切换页面或折叠窗口时声音生命周期不断裂。

apps/app/src/app/styles/app.css
packages/ui/src/styles/theme.css

落地「暖纸浅色 / 暖墨深色」两套语义 CSS 变量（--w-bg / --w-card / --w-bd / --w-sh / --w-box），配合 <meta name="color-scheme"> 与防闪烁脚本。

apps/desktop/src/shared/rpc/schema.ts
apps/desktop/src/main/index.ts

扩展 DesktopRPC 新增 audioUpdate / islandSync 请求与 audioStatusChanged 回推消息；在 before-quit 中释放原生播放器。

apps/desktop/electrobun.config.ts

当前配置为 exitOnLastWindowClosed: true。若支持 W5「关闭/收起主窗后由刘海持续控音」，需改为隐藏窗口驻留托盘/Island，并在显式 Quit 时停声。

06边界情况与状态行为表

边界场景预期行为
浏览器自动播放拦截 / 音频设备切换点击开启时若 AudioContext.resume() 被拒或设备断开，状态切为「声音被拦截」，声控区与 Island 出现重试入口；番茄倒计时继续走，不报错弹窗阻断。
休息段（短休 / 长休）声音切换默认在进入休息前 160ms 平滑淡出至静音，不打扰休息；若用户主动勾选「休息极轻伴奏」，音量自动压低至设定的 20%，回到下一专注段再淡入恢复。
暂停 / 提前跳过 / 终止队列暂停立即淡出停声，恢复专注自动续播；W4 模式下跳过当前任务时，若下一任务绑定了不同音色，180ms 交叉淡入淡出过渡；终止或完成最后一个番茄时彻底释放音轨。
W3 多轨滑块全部拉到 0%总开关保持已开启但音频引擎自动进入静默节能态（停止振荡/节点输出），界面标注「所有音轨为 0%」，任意拖高一轨立即恢复出声。
收起主窗口 / 无刘海屏幕 / Web 端收起主窗后声音与计时继续，菜单栏与 Island 显示实时微声波；在无刘海屏幕或浏览器访问 W5 时，自动回落为标题栏声控弹层与页面顶部迷你条，功能零缺失。
多标签页同时打开 Web 版通过 BroadcastChannel 协商单一音频播放权：新标签页主动点开声音时通知旧标签页淡出并显示「已由另一标签页接管」，杜绝重音叠播。
暗色模式切换与系统定时变暗支持「跟随系统 / 暖纸浅色 / 暖墨深色」三态；遵循不自动抹除用户手动锁定原则——即使用户在浅色系统锁定了深色，晚上系统变深后再切回浅色时仍保持深色，直到用户手动选回「跟随系统」。
键盘与减少动效偏好Esc 依次关闭当前打开的弹层/抽屉或收起固定的 Island；原生 <input type="range"> 支持方向键微调音量；开启 prefers-reduced-motion 时自动停用宠物跑动、声波条与雨滴/壁炉背景动效。

07建议路线与实现前要验证的事

推荐演进路线：首版落地「方案 1 暖墨暗色 + W1 标题栏声景弹层（含首页微氛围）+ Island 快捷静音」，改动面最小且 100% 守住方案 1 卡片桌面的留白与专注感；验证日活音频使用率后，再按用户画像决定往 W3（多轨混音） 还是 W4（AI 按任务配声景） 深化；待桌面端原生 Island 稳定后再接入 W5（刘海内直接调音量/切音色）。

1. 确认白噪音首版选型（W1–W5）

建议在上方演示里亲自走一遍「圈卡丢盒 → 开专注 → 开声 → 收起窗口 → 进休息」，重点对比 W1 的零侵入、W2 的常驻可见与 W3 的多轨叠音。

建议默认：首版 W1，保留 W3/W4 数据结构扩展位。

2. 音源方案：实时合成 vs 内置短音频循环

演示使用零体积 Web Audio 实时合成；正式版「白噪 / 粉噪」适合纯算法生成（零接缝），而「雨声 / 咖啡馆 / 壁炉 / 森林」建议内置 30–60 秒无缝压缩音频（Opus/AAC，单轨 < 600KB），听感更逼真。

待验证：桌面包体积预算与低功耗 CPU 占用实测。

3. 暗色模式对休息全屏的视觉约束

当前暖墨深色下，休息全屏从暖褐渐变进一步压暗至深炭，并把角色头顶气泡改为暗底奶白字，避免夜晚进入休息瞬间白泡刺眼。

待验证：在 OLED 外接屏与低亮度 MacBook 上核对夜间可读性。

4. 桌面端关窗驻留与耳机拔出中断

需把 electrobun.config.ts 的 exitOnLastWindowClosed 调整为窗口隐藏，并在 Swift Helper 中监听 AVAudioSession / CoreAudio 输出切换，耳机拔出时自动暂停白噪音避免公放。

待验证：Mac 合盖休眠跨段后唤醒，确认音频不会补播已过时段。
